# Submission Folder

This folder is the handoff bundle for Synthesis.

Contents:

- `submission-metadata.json` - the submission metadata object from the live Synthesis schema.
- `project-payload.json` - the ready-to-paste project payload with track UUIDs and placeholders for the remaining live values.
- `tracks.md` - chosen tracks and UUIDs.
- `sponsor-notes.md` - sponsor-facing summary of the MoonPay integration.
- `demo-script.md` - the short live demo flow.
- `checklist.md` - final readiness checklist.
- `conversation-log.md` - concise build narrative.
- `agent.json` and `agent_log.json` - simple agent artifacts.
- `manual-fallback.md` - what to do if the API submission path is unavailable.

Final publish is intentionally blocked until the user explicitly confirms it in the active session.
