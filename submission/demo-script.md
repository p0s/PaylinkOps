# Demo Script

1. Open the landing page.
2. Show the MoonPay sponsor framing and the demo/real mode split.
3. Open the dashboard.
4. Confirm the app is in demo mode.
5. Create a demo paylink.
6. Show the resulting receipt.
7. Open the ledger and point to the updated reconciliation state.
8. Open the receipts page and highlight the sanitized command output.
9. Switch to real mode.
10. Show the detected MoonPay CLI status and local wallets.
11. Create a live MoonPay paylink if the machine is configured.
12. Show the raw receipt and explain the fallback behavior if the CLI fails.

Target runtime: 60 to 120 seconds.
